# AuraLink 26.3 — инструкция на русском

1. Залей **все файлы этого проекта** в **корень нового GitHub-репозитория**. Папки `src`, `.github`, `companion-extension` должны быть рядом с файлом `build.gradle`.
2. Во вкладке **Actions** запусти **Build AuraLink for Minecraft 26.3**. Настоящий JAR будет доступен только при успешной сборке. Экспериментальные JAR из старых сообщений удаляй из папки `mods`.
3. Скачай **JAR** из Artifacts; установи в профиль **Minecraft 26.3 Fabric** вместе с соответствующим Fabric API.
4. В игре нажми **M**, открой вкладку **YANDEX**, нажми **COPY PAIRING KEY**.
5. В Microsoft Edge зайди на `edge://extensions`, включи режим разработчика, нажми **Загрузить распакованное** и укажи папку `companion-extension`.
6. Нажми на расширение AuraLink, вставь код из Minecraft и сохрани. На `music.yandex.ru` запусти музыку обычным способом и обнови вкладку.
7. В Minecraft в **YANDEX** доступны пауза, переключение песен, лайк, перемешивание и повтор через управление официальной веб-страницей. Название песни появится, если страница публикует MediaSession-метаданные.
8. Свои WAV-файлы копируй в `[папка профиля Minecraft]/auralink/tracks`, затем **M → WAV → SCAN**. Если есть MP3, используй `tools/import_audio.py` вместе с установленным FFmpeg.
9. Вкладка **LISTS** сохраняет локальные плейлисты, **QUEUE** управляет очередью, **LIKED** — избранное, **META** редактирует названия и метаданные локально.

**Важно:** это исходники альфа-версии. Реальная сборка и проверка в игре пока не подтверждены. Не обещаем полного повторения всех функций Overtune: нет полного набора расширенных событий, бесшовных переходов, автоматического импорта и встроенного поиска каталога Яндекса. Интеграция работает через открытый сайт Яндекс Музыки, а не через взломанный API. Пароль Яндекса никуда вводить не нужно, только на официальном сайте.
